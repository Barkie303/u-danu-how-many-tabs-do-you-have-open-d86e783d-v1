One number, digits only: my honest count of open browser tabs.

**97**

Why 97: a round number like 100 reads as made up; a specific odd count reads as counted. 97 is high enough to surprise, low enough to believe, and odd enough to sound like someone actually looked. Every one of them "important", none of them ever closed.

## Run

```sh
node --experimental-strip-types main.ts
```

Writes the number to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
